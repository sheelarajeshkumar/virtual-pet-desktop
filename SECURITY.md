# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest version on `main`.

| Version | Supported |
| --- | --- |
| `main` / latest `0.x` | Yes |
| Older snapshots | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/sheelarajeshkumar/virtual-pet-desktop/security/advisories/new) and include:

- Affected version or commit
- Platform and operating-system version
- Reproduction steps or proof of concept
- Expected impact
- Any suggested mitigation

You should receive an acknowledgement within seven days. The maintainer will coordinate validation, a fix, and disclosure timing. Please allow up to 90 days for remediation before public disclosure unless there is active exploitation or another urgent risk.

Never include API keys, signing certificates, personal data, or other secrets in a report, issue, commit, or log.
