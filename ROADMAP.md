# Roadmap

The roadmap communicates direction, not guaranteed delivery dates. Priorities may change based on contributor interest and platform feedback.

## Completed foundation

- Validated, runtime-loaded puppy and cat pet packs
- Configurable size, movement speed, sound, reduced motion, and care difficulty
- Persistent hunger, energy, happiness, cleanliness, and care actions
- Accessible settings and care windows

## Near term

- Add Windows runtime testing and packaging documentation
- Add a dedicated hide/show shortcut and visibility control
- Add screenshots and short demo recordings

## Next

- Add more community pets and behaviors
- Add per-pack movement profiles and a visual pack preview tool
- Add user-installed pack import/export
- Add signed release automation for macOS and Windows

## Later

- Safe extension hooks for community behaviors
- Optional AI companion that is disabled by default and never required by core pet behavior
- Independent AI conversation, memory, and voice toggles with a fully offline fallback
- Import/export for settings and pet packs
- Linux investigation after macOS and Windows are stable

Propose roadmap changes through a feature request or design issue before implementation.
