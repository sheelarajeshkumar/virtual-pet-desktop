# Roadmap

The roadmap communicates direction, not guaranteed delivery dates. Priorities may change based on contributor interest and platform feedback.

## Completed foundation

- Validated, runtime-loaded puppy and cat pet packs
- Configurable size, movement speed, sound, reduced motion, and care difficulty
- Persistent hunger, energy, happiness, cleanliness, and care actions
- Food/toy inventory, day/night routines, and opt-in care notifications
- Validated user-installed pet-pack import and removal
- Windows CI verification and unsigned NSIS packaging
- Accessible settings and care windows
- Configurable global hide/show shortcut and visibility control
- Directional pet-pack schema and visual animation preview
- Red fox pack plus safe declarative community behaviors
- Settings/care backup, restore, and community-pack export
- Optional Ollama/LM Studio/llama.cpp streaming chat, encrypted per-pet and semantic memory, personalities, background suggestions, voice controls, and confirmed actions/routines
- Protected signed-release workflow and Linux compile investigation
- Reproducible release-media capture guide plus reviewed macOS screenshots and demo
- Transparent production fox atlas for front/back diagonal walk and run

## Near term

- Complete the physical Windows 10/11 GUI checklist
- Capture reviewed Windows screenshots and a short demo recording
- Configure protected signing/notarization credentials and produce the first verified draft release

## Next

- Add community-authored pets, directional atlases, and behavior routines
- Add per-pack movement profiles after the schema is designed and reviewed

## Later

- Consider additional on-device AI providers only when they preserve the local-only boundary and existing provider contract
- Promote Linux from compile investigation only after overlay/tray behavior is tested on real desktops

Propose roadmap changes through a feature request or design issue before implementation.
