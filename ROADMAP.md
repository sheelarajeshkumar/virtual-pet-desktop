# Roadmap

The roadmap communicates direction, not guaranteed delivery dates. Priorities may change based on contributor interest and platform feedback.

## Near term

- Complete the cat sprite atlas and animation set
- Add Windows runtime testing and packaging documentation
- Add accessibility options for motion, sound, and pet visibility
- Add configurable movement speed and bark volume
- Add screenshots and short demo recordings

## Next

- Define a data-driven pet-pack manifest
- Load pets, animations, and sounds without changing core Rust enums
- Add pet-pack validation and preview tooling
- Add more community pets and behaviors
- Add signed release automation for macOS and Windows

## Later

- Safe extension hooks for community behaviors
- Optional interaction and needs systems
- Import/export for settings and pet packs
- Linux investigation after macOS and Windows are stable

Propose roadmap changes through a feature request or design issue before implementation.
