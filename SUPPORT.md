# Support

## Getting help

1. Read the [README](README.md) and [documentation](docs/ARCHITECTURE.md).
2. Search existing [issues](https://github.com/sheelarajeshkumar/virtual-pet-desktop/issues).
3. Open a bug report or feature request using the appropriate issue form.

When reporting a problem, include the operating system, app version or commit, reproduction steps, expected behavior, actual behavior, and relevant logs. Do not include secrets or private information.

Community support is best effort. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).
